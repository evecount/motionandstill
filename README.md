# Motion and Still (Cosmic Serenity)

> **Live Deployment:** [https://evecount.github.io/motionandstill/](https://evecount.github.io/motionandstill/)

A sovereign recursive fractal meditation engine and cosmic contemplation space based on pure mathematical geometry and real NASA observatory imagery.

---

## 🌌 Overview

**Motion and Still** weaves the precision of recursive mathematics with deep ambient soundscapes to create a meditative focus state. Rather than relying on arbitrary animations or static loops, the canvas dynamically computes real-time fractal geometry that breathes, unravels, and dissolves into a single focal breathing point across your chosen meditation duration.

Alternatively, drift beneath authentic deep-sky imagery captured by NASA and space observatories (galaxies, nebulae, and distant worlds), accompanied by generative audio and quiet whispered reflections.

---

## ✨ Features

- **Recursive Fractal Engine**: Dynamic Hilbert space-filling curves and recursive geometries that gradually unravel and simplify over the session duration, culminating in a single tranquil focal dot.
- **Deep Space Visuals**: High-resolution imagery curated across galaxies, nebulae, star clusters, and exoplanets.
- **Generative Soundscapes**: Multi-mode procedural audio synthesis powered by the Web Audio API:
  - **Drift**: Gentle binaural panning drone
  - **Cosmos**: Deep reverberant spatial pad
  - **Nocturne**: Melancholic low-frequency tonal resonance
  - **Epic**: Expansive orchestral harmonic envelope
  - **Ship**: Sub-bass cabin hum & interstellar ambient field
- **Whispered Reflections**: Periodic, grounding text prompts (*"breathe in"*, *"you are stardust"*, *"vast and quiet"*, *"let go"*).
- **Session Timers**: Tailored durations (1.5 min, 3 min, 5 min, or Endless exploration).

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Routing**: [TanStack Router](https://tanstack.com/router)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **UI & Icons**: [Radix UI](https://www.radix-ui.com/) + [Lucide Icons](https://lucide.dev/)
- **Audio & Rendering**: HTML5 Canvas 2D + Web Audio API
- **Deployment**: GitHub Pages via automated GitHub Actions workflow

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/evecount/motionandstill.git
cd motionandstill

# Install dependencies
npm install --legacy-peer-deps

# Start Vite development server
npm run dev

# Build production static bundle for GitHub Pages
npm run build
```
